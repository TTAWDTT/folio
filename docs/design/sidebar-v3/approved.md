# Folio 已批准的侧边栏设计

用户于 2026-11-03 确认按此设计直接实现。

## 唯一主界面基准

[01-chat-icons.png](01-chat-icons.png) 是当前主界面的视觉基准。它展示正常对话、模式展开与图标悬浮状态。旧 v2 与 v3 的文字按钮图片仅为历史草稿，不参与验收。

图外编号和拼图背景不属于产品。三个侧边栏使用同一套布局，约 360×760 逻辑像素。图标悬浮提示是覆盖层，不改变图标或正文位置。生成图中少量像素位置误差不代表悬浮时允许布局移动。

- 顶部为 Folio、新对话、课件、设置，去掉多余的工具栏与公共底栏。
- 对话正文直接排版，用户消息使用轻量圆角气泡，代码使用低对比背景。
- 底部输入框包含文本、模式入口与圆形发送按钮。
- 回答复制使用双层方框图标，重试使用环形箭头，不常驻显示文字。
- 所有图标有文字提示与可访问名称，禁用状态解释原因。
- 对话、菜单展开、悬浮、聚焦使用固定的内容位置。

## 行为合同

保留 [interaction-spec.md](interaction-spec.md) 的完整行为要求，并应用 [icon-spec.md](icon-spec.md) 的最新图标修订。下面这些行为属于验收范围。

1. 模式只有问答、练习、生成测试、提交信息。第一次点击打开，再点击只关闭。同一指针手势不能关闭后重新打开。Esc、外部点击和选中当前项均关闭菜单。
2. 课件、设置和测试预览是明确的辅助页面。进入和返回保留原对话、模式、草稿、上下文与阅读位置。它们不挤压主对话。
3. 每个模式独立保留草稿与光标位置。切换只改变下一次输入用途，正在执行的任务使用其捕获的模式和上下文。
4. 发送与停止使用同一控件。生成时仍能编辑下一条草稿。停止保留已收到内容，拒绝晚到结果，不误发下一条。
5. Enter 发送、Shift+Enter 换行，IME 候选确认不发送。输入框最多六行，之后内部滚动。
6. 用户向上阅读或选择文字时不强制跟随。回到最新明确恢复跟随。来源默认收起，点击来源标题才打开文件。
7. 复制反馈在原图标位置，重试复用原请求，不覆盖下一条草稿、不重复用户行。
8. 测试先预览后写入，保留解析、目标目录、同名文件、变更和可写性检查。
9. 提交候选由用户显式复制或填入，保留暂存快照与原提交框检查，不自动改剪贴板、填写或执行提交。
10. 保留课件的共享、原子更新、来源与证据边界，以及凭证的端点绑定、脱敏和系统钥匙串存储。无 Key 时保留本地课件检索入口，并在输入附近明确模型不可用原因。
11. 练习保留三题，每题解析独立展开。设置返回与取消不保存，移除 Key 先标记修改，保存后生效。
12. 反馈不延迟命令，局部过渡可中断，遵循系统减少动态效果设置。

## 验收与证据

静态图片只证明设计内容。实际代码必须生成生产 Swing 的截图，与本图逐项比较布局、字级、间距、控件位置与文案，并验证窄宽度和主题刷新。

交互验收覆盖真实 Swing 事件顺序、任务取消、草稿恢复、输入法、阅读位置和受保护写入。自动测试与生产渲染不能替代尚未完成的真实 IntelliJ 操作检查，任何缺口需明确保留。

禁止使用会占用用户系统鼠标或抢占窗口焦点的桌面自动化。只使用不会影响用户输入的检查方式。
