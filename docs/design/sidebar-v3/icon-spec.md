# 已批准的图标与悬浮提示

用户要求回答下方的复制、重试改成图标，所有图标在悬浮时显示文字。批准图为 [01-chat-icons.png](01-chat-icons.png)，由内置 image_gen 修订。用户已授权按图实现，整体范围见 [approved.md](approved.md)。

## 回答操作

复制使用双层方框图标，重试使用环形箭头图标。两者不常驻显示文字。小图标保留完整点击区域，悬浮只改变局部背景，不移动按钮或正文。

复制成功时图标暂时变为对勾，悬浮提示变为“已复制”，随后恢复。失败时提示“复制失败，请重试”。重试期间提示“正在重新生成”，阻止重复请求。

## 所有图标的统一规则

鼠标短暂停留后显示文字提示，延时使用统一规则。离开、点击或滚动后关闭。提示浮在内容之上，不挤动布局、不抢焦点，并自动避开窗口边界。键盘聚焦同样能读取功能说明，辅助功能名称与提示一致。

带文字的菜单项目中，图标沿用该项目的功能名称。状态图标解释当前状态。不可用图标仍说明功能及不可用原因。不能只靠图形或颜色传达含义。

| 图标用途 | 默认提示 |
| --- | --- |
| 新对话 | 新对话 |
| 文件夹 | 课件 |
| 齿轮 | 设置 |
| 回答复制 | 复制回答 |
| 用户消息复制 | 复制消息 |
| 代码复制 | 复制代码 |
| 提交候选复制 | 复制提交信息 |
| 重试 | 重新生成 |
| 发送 | 发送消息 |
| 停止 | 停止生成 |
| 模式入口 | 选择模式 |
| 引用展开与收起 | 展开课件引用／收起课件引用 |
| 返回 | 返回对话，其他页面使用实际返回目标 |
| 文件省略号 | 更多文件操作 |
| 密码可见性 | 显示本次输入的 Key／隐藏 Key |
| 移除上下文 | 移除代码上下文 |

提示根据真实操作和状态变化。无法发送时，例如显示“发送消息：请先连接模型”，不只显示“不可用”。所有后续页面新增的图标也必须遵循此规则。

静态图里的“设置”和“复制回答”是悬浮提示示例。静态图不证明实际悬浮行为，运行验证需另行记录。
